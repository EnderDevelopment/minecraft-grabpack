# Minecraft GrabPack Plugin

Adventure Adventures is a Minecraft Paper plugin that adds GrabPack gameplay with custom left and right hand items, target detection, entity pulling, player launching, red particle beams, cooldown protection, and permission-controlled commands.

## Install

1. Use Java 21 or newer.
2. Run a Paper 1.21.11 server.
3. Build the plugin with Maven:

```bash
mvn package
```

4. Copy the generated `target/plugin.jar` file into the server's `plugins` folder.
5. Start or restart the Paper server.
6. Confirm that the plugin is enabled in the server console.

## Use

1. Join the server and run:

```text
/grabpack
```

2. Select the red GrabPack
